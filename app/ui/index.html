How do Webhook URL & Secret work?
Inbound HTTP (127.0.0.1:7842): Lets a local bot, script, or Apple Shortcut control wakey via GET /status and POST /command (e.g. {"cmd":"awake_for","duration":"2h"}).
Outbound Webhook URL: Optional URL (e.g. n8n, Slack, Discord, or Grok relay) where wakey POSTs JSON notifications when a wake session starts, warns before expiry, or stops. Leave blank if unused.
Webhook Secret: Any shared secret string you choose; wakey sends it in the X-Wakey-Secret HTTP header so your webhook server can verify requests are from wakey.
